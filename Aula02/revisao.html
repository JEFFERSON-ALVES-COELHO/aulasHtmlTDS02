Entender a importância das tags Semânticas

Utilizar as tags HTML de forma Semântica é importante para garantir a acessibilidade e a compreensão do conteúdo pelo usuarios e pelo mecanismo de busca.

Tags importantes

  • header: Define o cabeçalho do site
  • nav: Define a área de Navegação
  • main: Define o conteúdo principal do site
  • section: Define uma seção do conteudo
